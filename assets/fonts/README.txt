Arabic font: Alexandria (SIL Open Font License, free to self-host)

1. Open https://fonts.google.com/specimen/Alexandria and click "Get font" > "Download all".
2. From the zip, copy this ONE file into this folder, keeping its name:
      Alexandria-VariableFont_wght.ttf
   (one variable file covers Light, Regular, Bold and every weight in between)
3. Deploy. Until the file exists the Arabic pages simply fall back to Noto Sans Arabic / Segoe UI / Tahoma.

Self-hosting keeps the site free of third-party requests, which matches the Privacy Policy.
